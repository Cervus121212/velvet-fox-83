Ember Sigils — a duel of rune cards. Play sigil cards against the Hollow Sigilist: ride the elemental wheel (Ember beats Leaf, Leaf beats Storm, Storm beats Frost, Frost beats Ember) for +3 edge damage, read the rival's intent and answer it, and be the first to bring the other side to 0 life. A complete card game with a title screen, a live table showing both hands, cards with readable values, suits and costs, visible life totals, and win and loss screens. Keyboard and mouse, no network, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
